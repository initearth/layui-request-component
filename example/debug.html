按顺序操作，观察响应结果与调试日志

快速开始

  1. 点击 登录签发，获取 accessToken（2 分钟有效）与 refreshToken（1 小时有效）
  2. 点击 请求鉴权 /me，验证请求头 Authorization: Bearer 注入与 JWT 验签
  3. 点击 过期自动刷新，观察 401 → refresh → 重试的完整链路

按钮速查

  • 解析 Token：Base64URL 解码 Header / Payload / Signature 三段
  • 模拟已过期：写入 exp 已过期的 JWT，触发 401 刷新
  • 模拟签名错误：写入签名非法的 JWT，验证验签失败
  • 手动刷新：用 refreshToken 换取新的 accessToken
  • 403 拦截：验证权限错误不清除 Token
  • 清除：删除 layui.data 中的双 Token
观察要点：「响应结果」展示接口原始返回；「调试日志」捕获含 [layui-request] 的拦截器日志；「JWT Payload」区实时展示三段解码内容与 exp 过期时间，顶部倒计时每秒刷新。
